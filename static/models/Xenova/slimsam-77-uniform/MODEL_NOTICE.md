# SlimSAM model notice

This directory contains ONNX weights and configuration files from
[`Xenova/slimsam-77-uniform`](https://huggingface.co/Xenova/slimsam-77-uniform),
an ONNX/Transformers.js conversion of `nielsr/slimsam-77-uniform`.

The model is distributed under the Apache License 2.0. See `LICENSE` in this
directory. The bundled fp16 files are used with WebGPU and the quantized files
provide a WASM/CPU fallback.
